# The Moment 디자인 시스템

새 Figma 디자인 시스템을 준비하고 있습니다. 기존 디자인 시스템은 폐기했으며,
컴포넌트는 새 Figma 디자인 시스템이 확정된 뒤 구현합니다. 지금은 UI 컴포넌트가 없습니다.

## 지금 확인할 수 있는 것

- **Tokens**: 빌드된 패키지의 `values`를 읽는 색상·간격·반경·타이포그래피 문서입니다.
- **CSS contract**: 일반 CSS, Tailwind v4의 두 import 순서, 소비자 토큰 덮어쓰기 검증입니다.

현재 토큰은 코드 파이프라인 검증용 **placeholder**입니다. 실제 브랜드 디자인으로 사용하지 마세요.

## 소비 방식

Storybook은 소스 별칭 없이 `@themoment-team/design-system-react`의 공개 export와 빌드 산출물만 사용합니다.
일반 소비자는 `styles.css`를 가져오고, Tailwind v4 사용자는 `tailwindcss`와 패키지의 `styles.css`, `tailwind.css`를 가져옵니다.

확정 토큰을 교체하고 `pnpm --filter storybook build`를 실행하면 토큰 문서도 함께 갱신됩니다.
